# Git Practice
Learning Git step by step.
I am practicing Git merge conflicts locally and collaborating through GitHub's web editor.
Practicing how to pull remote changes into my local repository.

## Cloning This Repository

To download this repository onto your local machine, run:

```bash
git clone git@github.com:KevinLemon112/Git-Practice.git
```

Navigate into the repository directory:

```bash
cd Git-Practice
```
